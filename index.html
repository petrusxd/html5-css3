01

Variáveis & Tipos

@property declara custom properties com tipo (<color>, <number>, <length>, …), valor inicial e política de herança. Sem @property uma var é apenas um token textual; com ela, a engine impõe tipo na atribuição e habilita interpolação animada coerente. 

@property --energia {
  syntax: "<number>";   /* tipo */
  initial-value: 0;
  inherits: false;
}
:root {
  --base: 16;        /* int  */
  --cor:  #5eead4;  /* color*/
  --dobro: calc(--base * 2); /* expr */
}
--base
--dobro = base*2
--cor

Resolução: tempo de cascata (uma vez por mudança); calc() avaliado na engine. Valores numéricos via counter-reset + counter() — provam que o número aparece da computação CSS, não de HTML estático.

02

Funções nativas novo · 2025

@function (CSS Functions & Mixins L1, W3C FPWD 15 mai 2025; Chrome 139+): assinatura com parâmetros tipados, defaults, tipo de retorno, e result: como expressão. Composição: chamável em qualquer valor de propriedade. Sem suporte ⇒ fallback via @supports(...). 

@function --dobrar(--v) {
  result: calc(--v * 2);
}
@function --clarear(--c <color>, --n <number>: .22)
  returns <color> {
  result: oklch(from --c calc(l + --n) c h);
}
.caixa {
  padding: --dobrar(12px);   /* 24px */
  background: --clarear(#1d4ed8);
}
--dobrar(12px) → de padding
--clarear(#1d4ed8)

Detecção de capacidade: @supports (background: --clarear(#1d4ed8)) só aplica o ramo nativo onde a engine resolve a função; fora disso, valor literal.

03

Fluxo de decisão (if / else)

(a) Inline: if() (CSS Values L5, snapshot set/2025) avalia style(...), media(...), supports(...) e retorna um valor — ternário tipado dentro de qualquer propriedade. (b) Universal: #x:checked ~ alvo — projeta o estado de um input sobre qualquer elemento descendente do ancestral comum à direita. Disponível desde CSS3 (2011). 

/* (a) if() nativo — 2025 */
button {
  color: if(
    style(--tema: dark): white;
    else: black
  );
  width: if(
    media(width < 600px): 100%;
    else: 320px
  );
}

Avaliado a cada resize; redimensione a janela cruzando 600 px para observar a transição.

/* (b) if/else universal com :checked */
#porta:checked ~ .saida::after {
  content: "ACESSO LIBERADO ✓";
  color: #34d399;
}
#porta:not(:checked) ~ .saida::after {
  content: "ACESSO NEGADO ✕";
  color: #f87171;
}

Loops & Iteração

Computação real: somador completo (1 bit)

Full-adder de 1 bit. Soma = A ⊕ B ⊕ Cin (paridade ímpar; ativo em 001, 010, 100, 111). Carry = maioria(A, B, Cin) (≥ 2 entradas em 1; ativo em 011, 101, 110, 111). Implementação: enumeração das 8 combinações com :checked/:not(:checked) em cadeia ~. Cascateado em N bits ⇒ ripple-carry adder de N bits — base de qualquer ULA.

Caso de teste: A=1, B=1, Cin=0 ⇒ Soma=0, Carry=1 (binário 10₂ = 2₁₀).

Estado em input; projeção em CSS via :checked, :has(), combinador ~ e counter-*. Os filtros usam max-height: 0 (não display: none) para manter os itens no fluxo do counter — o total permanece correto em qualquer filtro.

Calculadora

Entrada simétrica de comprimento variável, A,B ∈ [0, 9999] (4 slots por operando — D_AB=4 é o teto teórico de × via counters int32 do CSS Lists 3: contribuição parcial máxima 9·9·10^(2·D_AB−2) deve caber em 2³¹−1). Operações: + − via counters posicionais (Σ aₖ·10^(m−1−k)); × via produtos parciais (Σ aᵢ·bⱼ·10^(m+n−2−i−j)); ÷ mod ^ via tabela de decisão enumerada com subdomínio per-op: ÷ ∈ A[0,999]×B[0,99] (122 100 regras — divisor de até 2 dígitos cobre 999÷77, percentuais); mod e ^ ∈ A[0,999]×B[0,9] (11 100 cada). Bignum exato em ^, decimal finito ou 4 casas+… em ÷, ÷0! e mod0! tratados. FSM de entrada: operação fecha o número atual em qualquer comprimento. C = <button type="reset"> nativo.

Source — FSM + aritmética

Estado: radio por slot. Cada tecla expõe 6 rótulos sobrepostos (lbl-a0..a2, lbl-b0..b2). A FSM seleciona exatamente um lbl ativo por vez via pointer-events condicionado em :has(...) / :not(:has(...)). O slot A_k exige :not(:has([name=op]:checked)) — assim qualquer op fecha N1 (a operação derruba a precondição de roteamento de A e B0 assume). N1 = Σ Aₖ·10^(m−1−k) com m = nº de slots A marcados; counter res acumula contribuições posicionais por counter-increment em acumuladores disjuntos (.accAk, .accBk, .accPij) — somam sem se sobrescrever. Para ÷/mod/^, uma regra exata por (op, A, B) define content; fora do subdomínio, content: "—".

CSS — máquina de estados de entrada (comprimento variável)
/* FSM em 6 estados (3 slots de A + 3 de B). pointer-events: none */
/* desativa todos os rótulos; cada precondição :has/:not(:has) abre UM. */
.lbl { pointer-events: none; }

/* A_k = próxima posição livre em A ⇔  A_{k-1} marcado ∧ A_k não marcado ∧ op não marcada. */
/* :not(:has([name=op]:checked)) é a chave: a operação derruba o roteamento de A em qualquer m. */
.calc-form:not(:has([name="A0"]:checked)):not(:has([name="op"]:checked)) .lbl-a0 { pointer-events: auto; }
.calc-form:has([name="A0"]:checked):not(:has([name="A1"]:checked)):not(:has([name="op"]:checked)) .lbl-a1 { pointer-events: auto; }
.calc-form:has([name="A1"]:checked):not(:has([name="A2"]:checked)):not(:has([name="op"]:checked)) .lbl-a2 { pointer-events: auto; }

/* B_k: B0 exige op marcada (sucessor da operação); B1/B2 dependem apenas de B_{k-1}. */
.calc-form:has([name="A0"]:checked):has([name="op"]:checked):not(:has([name="B0"]:checked)) .lbl-b0 { pointer-events: auto; }
.calc-form:has([name="B0"]:checked):not(:has([name="B1"]:checked)) .lbl-b1 { pointer-events: auto; }
.calc-form:has([name="B1"]:checked):not(:has([name="B2"]:checked)) .lbl-b2 { pointer-events: auto; }
CSS — aritmética: counters, produtos parciais e tabela
/* + −  : counter posicional. Uma regra por (op, X∈{A,B}, m, k, v) emite */
/*        counter-increment: res  ±v·10^(m-1-k)  no acumulador .acc{X}{k}. */
/* len(A) detectado por :has(A_{m-1}:checked):not(:has(A_m:checked)).      */
.calc-form:has(#op-add:checked):has(#A0_5:checked):has([name="A1"]:checked):not(:has([name="A2"]:checked)) .accA0
  { counter-increment: res 50; }   /* A=5_ ⇒ m=2 ⇒ A0=5 contribui 5·10 */
.calc-form:has(#op-add:checked):has(#A1_3:checked):has([name="A1"]:checked):not(:has([name="A2"]:checked)) .accA1
  { counter-increment: res 3; }    /* …A1=3 contribui 3·1; A=53 */

/* ×    : produtos parciais. peso(i,j) = 10^(m+n-2-i-j). Acumulador .accPij */
/*        por par para evitar sobrescrita (counter-increment soma entre elementos). */
.calc-form:has(#op-mul:checked):has(#A0_6:checked):has(#B0_6:checked):has([name="A1"]:checked):not(:has([name="A2"]:checked)):has([name="B1"]:checked):not(:has([name="B2"]:checked)) .accP00
  { counter-increment: res 3600; }   /* 66×66: A0·B0·10² = 36·100 */

/* ÷ mod ^ : ROM enumerada A∈0..999 × B∈0..9 (33 300 linhas).             */
/* content sobrescreve o default counter(res); especificidade maior vence. */
.calc-form:has(#op-pow:checked):has(#A0_9:checked):has(#A1_9:checked):not(:has([name="A2"]:checked)):has(#B0_9:checked):not(:has([name="B1"]:checked)) .dispR::after
  { content: "913517247483640899"; }   /* 99^9 = valor exato de 18 dígitos */

BIT-4

O programa-demo decrementa R0 de 3 a 0 em laço JNZ. Source — FSM de 3 estados controla play/pause/reset
